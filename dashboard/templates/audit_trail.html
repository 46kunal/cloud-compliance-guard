Hash-chained audit trail

Chain integrity: checking…

Each entry stores the hash of the one before it. Editing any entry breaks every hash after it. This detects tampering; it does not prevent someone with database write access from rewriting the whole chain, which is why the latest hash should be anchored somewhere they cannot edit.

Tamper-proof anchors

Anchor check: checking…

After each scan, the latest chain hash is written to a locked, signed receipt that a database writer cannot edit. If someone rewrote the whole chain, it would no longer match these receipts.
